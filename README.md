# 🌐 My First Portfolio – Arava Hithesh Prem

Welcome to my first personal portfolio website!

This project is where I started bringing my technical skills, projects, certifications, and experience together into one place. I built it using **HTML and CSS**, and deployed it using **Git and GitHub Pages**.

The goal was to create a personal website where recruiters, developers, and anyone interested in my work could learn more about me and explore the projects I've worked on.

🔗 **Live Website:** [View My Portfolio](https://hithesh1120.github.io/portfolio/)

## 📌 About the Portfolio

This portfolio serves as a central place to showcase my background in Computer Science, technical skills, development projects, certifications, and professional interests.

It reflects my early journey into web development and my interest in building clean, accessible, and user-friendly websites.

## 🚀 Deployment

I used Git and GitHub Pages to publish the portfolio online.

The basic workflow:

1. Created the website using HTML and CSS.
2. Managed the source code using Git.
3. Uploaded the project to GitHub.
4. Enabled GitHub Pages to host the website.
5. Made the portfolio accessible through a public URL.
